# Study Buddy TV

**A TV-friendly study and quiz prototype** built with HTML, CSS, and JavaScript.

## What it does
- Quick Quiz with 5 multiple-choice questions
- Daily Challenge using mixed question order
- Revision cards with reveal/flip interaction
- Answer feedback, score points, and session results
- Keyboard directional navigation and Escape-to-home
- Large, readable layout designed with TV viewing in mind

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Navigate with arrow keys and Enter, or use a mouse.

No build step or dependencies are required for this browser prototype.

## Current status and limitations
This repository currently contains a **browser prototype**. It has **not yet been verified on Fire TV or VegaOS**, and TV runtime compatibility must not be assumed from browser testing alone. The current questions and revision content are sample content.
